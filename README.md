# 🚀 C# & .NET Development Portfolio

A curated collection of backend applications, system architectures, and software engineering artifacts developed throughout my advanced C# programming course. These projects showcase object-oriented programming (OOP), enterprise design patterns, and rigorous system design methodologies.

---

## 🛠 Core Technical Skills Gained

### 🧠 Language & Core Architecture
* **Advanced C# Proficiencies** – LINQ, generics, asynchronous programming (async/await), and lambda expressions.
* **OOP & Clean Code** – Inheritance, polymorphism, encapsulation, and strict adherence to SOLID design principles.
* **Memory & Performance** – Efficient resource management using the `IDisposable` pattern and garbage collection optimization.

### 📐 Systems & Frameworks
* **Framework Mastery** – .NET Core / .NET API development and dependency injection containers.
* **Data Access** – Relational database connectivity via Entity Framework Core (EF Core) and raw ADO.NET queries.
* **Testing & Quality Assurance** – Automated unit testing and test-driven development (TDD) principles.

## 📝 Course Reflection & Engineering Mindset

### Maintainability, Readability, and Adaptability
* **Writing Clean Code:** I prioritized code maintainability by writing highly descriptive method signatures and enforcing single-responsibility components. 
* **Adapting to Change:** Interface-driven abstraction ensures that the systems can easily swap out data storage layers (e.g., transitioning from memory mockups to active SQL servers) without breaking downstream business logic.
* **Future Professional Application:** The technical writing skills practiced through the BRD and SDD will directly translate to onboarding software teams and mapping stakeholder desires to production-ready applications.

### Prerequisites
* [.NET SDK](https://microsoft.com) (Version 8.0 or later)
* An IDE such as [Visual Studio](https://visualstudio.microsoft.com/) or [VS Code](https://visualstudio.com)

### Step-by-Step Installation
1. Clone this repository locally:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the specific project directory:
   ```bash
   cd src/YourProjectDirectory
   ```
3. Restore dependencies and compile the codebase:
   ```bash
   dotnet restore
   dotnet build
   ```
